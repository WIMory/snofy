7 个核心功能，1 个核心逻辑

真实到店，真实打卡，真实点亮——这就是足迹地球

📌

发布推文

推荐你常驻城市的小店美食、风景、娱乐。美食 / 风景 / 娱乐三类，用真实体验说话。

👣

到店打卡

GPS 围栏验证 + 实时拍照 + 文字评价。必须在场才能打卡——每个足迹都真实可验证。

🏙

城市点亮

打卡次数解锁城市视觉升级：彩色 → 光晕 → 金名 → 专属图标。你让这座城市亮了。

🌍

地球仪

所有足迹和推文在地球仪上呈现。足迹模式 / 推荐热力 / 功能区，三种视图自由切换。

❤️

真实评价

给用户发声的机会。好评、中性、差评都可以——真实体验比推文更有参考价值。

🔖

想去清单

收藏推文到"想去"清单。旅行前整理目的地，出行时快速找到对应推文。

⭐

点赞与互动

对推文表态。点赞数影响足迹颜色：铜 / 银 / 金，荣誉来自真实认可。

三步，完成你的足迹闭环

从发布推荐开始，到城市点亮结束——每一步都真实可见

1

发布你的第一条推文

写下你常去的小店、你看过的风景、你玩过的地方。配图、配地点，让推文在地球仪上找到它的位置。

2

有人看到推文，真实到店打卡

其他人看到你的推荐，到店后 GPS 验证 + 拍照打卡，留下真实评价。你的推荐真正产生了价值。

3

城市被点亮，你的推荐被认可

每一次真实打卡让城市更亮。你的推荐让更多人发现了这座城市的宝藏。

拒绝"照骗"，只做真实

每一个打卡都必须满足的条件，让虚假无处遁形

📍

GPS 必须在场

打卡必须位于店铺半径 50 米内，大型景区需进入多边形围栏。模拟定位直接拒绝。

📷

实时拍照

必须调用相机，禁止从相册上传。照片叠加隐形水印，pHash 去重检测。

🛡

四层反作弊

技术验证 + 机制约束 + 经济壁垒 + 社区陪审。72 小时延迟发放，陪审团制度。
